El proyecto es una web DirectoRadio.com donde poder escuchar emisoras de radio de diferentes tipologias y diferentes idiomas y localizaciones.

El usuario podrá visualizar un listado de emisoras de radio para poder escoger cual quiere escuchar.

Este listado tendra un buscador de emisoras, este buscador sera un buscador por IA donde el usuario podrá escribir el tipo de emisora que esta buscando en modo prompt escrito o hablado. Por ejemplo: "Quiero una emisora de EEUU que hable de las ultimas noticias", "Buscame una emisora de Portugal que emita musica Fado" 

Al seleccionar una emisora vera el detalle de la misma con algo de informacion referente a la emisora y podra reproducir su streaming.

La informacion que vamos a tener de cada emisora sera: 
    Nombre
    Descripcion
    Imagen Logotipo 
    Url del streaming
    Url de la pagina web
    Pais de origen
    Tipo o genero (musical "Pop, Electronica, Rock, Jazz, Clásica, Variada", noticias, deportes, generalista)
    Idioma de emision
    Fecha de Alta
    Fecha Ultima Modificacion
    Status (Activa,Desactivada,Eliminada)
    Numero de visualizaciones o reproducciones
    Evaluacion media
    Numero de evaluaciones 

Dentro del detalle de la emisora el usuario podrá evaluar la emisora en formato estrellitas

Dentro del detalle de la emisora tambien podra activar la transcripcion escrita al idioma que el escoga. 

Tambien tendra una opcion de traduccion instantanea de lo que se esta reproduciendo pudiendo escoger el idioma en el que quiere reproducir el streaming 

Por ahora no sera necessario login de usuario para realizar ninguna acción en la web, mas adelante lo vamos a incluir

La web debe funcionar y verse correctamente desde cualquier dispositivo
